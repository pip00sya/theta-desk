# Как построен первичный рейтинг

Оценка автоматическая, по официальным пяти критериям, насколько они видны снаружи.
Лайки НЕ участвуют. Все 108 заявок обработаны одинаково.

| Критерий | Максимум | Как измерено |
|---|---|---|
| Technology Implementation | 5 | по 1 баллу за: MCP, CLI, реальные опционные конструкции (mleg/кондор/спред), Trading API и исполнение, аудит/журнал/сверка |
| P&L Performance | 3 | 2 балла если в описании есть конкретное число прибыли или процента, 1 балл за названное число сделок/решений |
| Creativity & Originality | 3 | по 1 баллу за каждый нетривиальный механизм из списка (conformal, Kalman, Lean 4, дилерская гамма, граф гипотез, повтор, абляция, срочная структура и т.д.), максимум 3 |
| Presentation & Execution | 3 | 3 балла за собственный домен, 2 за хостинг-платформу (Vercel/Streamlit/Render), 1 за ссылку на GitHub или голый IP, 0 если демо нет |
| Social engagement | — | снаружи не измеряется, исключён |

## Чего эта оценка НЕ умеет

- Реальный P&L не виден. Балл даётся за то, что команда НАЗВАЛА цифру, а не за её размер.
- Оригинальность по ключевым словам груба: «out-of-sample» ловится и там, где это дежурная фраза.
- Качество демо не проверено, только тип хостинга.
- Видео не учтено вообще.

Поэтому это ОТБОР для глубокого изучения, а не итоговый рейтинг.
